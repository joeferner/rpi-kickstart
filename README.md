# rpi-kickstart has moved

This crate is now developed in the
[rpi-hal repository](https://github.com/joeferner/rpi-hal/tree/main/kickstart),
together with rpi-hal, rpi-hal-embassy and rpi-loader.

- **Nothing changes for users.** The crate is still
  [`rpi-kickstart` on crates.io](https://crates.io/crates/rpi-kickstart);
  your `Cargo.toml` needs no change.
- **Issues** moved there, with the `kickstart` label. Old issue links
  redirect.
- **Pull requests** stay here.
- **Releases** from now on are tagged `kickstart-v<version>` there.
  Releases up to v0.2.0 remain on this repository's release page.
- **Documentation:** [docs.rs/rpi-kickstart](https://docs.rs/rpi-kickstart).

This repository is archived and read-only.
